# Blockfall

Небольшая браузерная игра в стиле классического Тетриса. Игровое поле — 10 × 20 клеток; доступны все семь стандартных фигур, вращение, ускоренное падение, очистка линий, очки, уровни и рекорд.

При очистке линий проигрываются синтезированные звуки и показывается анимация. Для четырёх линий одновременно считается «Тетрис». Рекорд сохраняется в локальном хранилище браузера.

## Управление

| Клавиша | Действие |
| --- | --- |
| `←` / `→` или `A` / `D` | Переместить фигуру |
| `↑` или `W` | Повернуть фигуру |
| `↓` или `S` | Ускорить падение |
| `Пробел` | Пауза / продолжить |

На телефонах используйте экранные кнопки под игровым полем. Удерживайте `←`, `→` или `↓` для повторного действия.

## Запуск без сервера

Загрузите проект и откройте `index.html` в современном браузере. Сборка, сервер, установка пакетов и подключение к интернету для игры не нужны.

## Публикация на GitHub Pages

1. Загрузите файлы проекта (`index.html`, `style.css`, `game.js` и `README.md`) в корень GitHub-репозитория.
2. В настройках репозитория откройте **Pages**.
3. В разделе публикации выберите **Deploy from a branch**, нужную ветку (например, `main`) и папку **/(root)**, затем сохраните настройки.
4. После завершения публикации откройте адрес сайта, указанный GitHub Pages в этом разделе.

Все ресурсы подключаются относительными путями из репозитория. Внешние библиотеки, шрифты, изображения и аудиофайлы не используются.

## Файлы проекта

- `index.html` — разметка игры.
- `style.css` — оформление и адаптация для небольших экранов.
- `game.js` — игровая логика, звуковые эффекты и анимации.
- `README.md` — описание, управление и инструкции.
